Follow these base Ruby style rules:
- Use 2 spaces for indentation, never tabs
- Keep lines under 100 characters
- Add '# frozen_string_literal: true' at the top of every Ruby file
- Use snake_case for variables, methods, and file names
- Use CamelCase for classes/modules
- Use SCREAMING_SNAKE_CASE for constants
- End each file with a newline
- Use single quotes for non-interpolated strings
- Use double quotes only for interpolated or special-character strings
